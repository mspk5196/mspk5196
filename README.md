## ☁️ MSPK Cloud Storage

### *Founder & Product Architect*

[mspkapps.in](https://mspkapps.in?utm_source=chatgpt.com)

A self-hosted cloud storage platform designed around **user-owned infrastructure**.

Instead of forcing users to move their data to a centralized cloud, the system allows storage to remain on their own hardware while providing centralized authentication, synchronization, and access control.

**Architecture**

